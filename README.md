# 实验二：简单网络的设计

《计算机网络》实验二的完整设计与展示项目。内容包括现有 10Base-T 网络升级、线缆与设备选型、设备位置和端口预算、Internet 接入、三个 VLAN 的 IP 地址规划、单臂路由、NAT/PAT，以及问题与解决办法。

## 项目内容

- 响应式实验展示首页，支持 VLAN 地址表筛选和打印。
- 完整中文实验报告。
- 可缩放的 SVG 网络拓扑，标明 30 台 PC、三台交换机、路由器、线缆距离及 VLAN 网关。
- 厂商中立的交换机与路由器逻辑配置模板。
- 原始 `/26` 划分为三个业务 `/28` 和一个保留 `/28`，每个业务网段包含 10 个 PC 地址与 1 个网关。

## 本地运行

本项目是无框架、无外部依赖的静态网站，不需要安装或构建。

### 方法一：直接打开

使用浏览器打开根目录的 `index.html`。核心内容不依赖 JavaScript；禁用 JavaScript 后仍可阅读完整方案，仅地址表筛选和导航高亮不可用。

### 方法二：启动本地静态服务器

确保已安装 Python 3，在本目录执行：

```bash
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000/
```

停止服务器时，在终端按 `Ctrl+C`。

## 公网部署

将本项目作为 **StaticWeb（静态网站）** 发布，上传内容必须包含 `index.html`、`assets/`、`docs/`、`config/` 和 `README.md`，并保持相对目录结构不变。

- 构建命令：无。
- 发布目录：项目根目录；若平台要求单独目录，则把上述文件复制到该目录。
- 默认入口：`index.html`。
- 访问策略：所有人可见（公开），不能设为仅自己可见。
- 不需要 Node.js 服务、数据库、环境变量或密钥。

在 Trae 中可使用部署插件选择 StaticWeb 并设为“所有人可见”；在其他静态托管平台中，将本项目发布目录按平台要求上传即可。部署完成后，应在未登录的浏览器或隐私窗口验证公网 URL，再将真实 URL 写回本文件的“在线提交信息”。

## 实施注意

`config/` 中的文件用于表达配置逻辑，并非特定品牌的可直接执行命令。实际部署前须根据设备型号转换语法，填写运营商真实 WAN、下一跳与 DNS 参数，并依次验证同 VLAN、网关、跨 VLAN、默认路由、NAT、Internet、铜缆链路和光模块状态。当前项目只声明静态设计校验已完成，不虚构上机测试结果。
